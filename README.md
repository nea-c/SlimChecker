# SlimChecker

適応されたスキンがスリムかどうかチェックするライブラリデータパック。

Minecraft datapack to check if the applied skin is slim.

## 最新

r2

## 対応バージョン

MinecraftJE 26.3（データパック形式121.0）

旧版は [`1.21.8-26.2`](https://github.com/nea-c/SlimChecker/tree/1.21.8-26.2) ブランチに保存。
旧版の確認済みバージョンは1.21.8。26.2では公式サーバーによるコマンド構文とルートテーブルの読み込みを確認。


## 使用方法

判定対象のプレイヤーを実行者にして、以下のように実行。
```mcfunction
## 例
execute if function #slim_checker: run say My skin model is 'Slim'
execute unless function #slim_checker: run say My skin model is 'Wide'
```

初回のみ一時的な `item_display` からプロフィールを取得し、同じtick内に削除する。
判定結果は `slim_checker.is_slim` に保存する。
取得時に `slim_checker.leave_game` を判定結果と同じ値へそろえ、退出によって値が変わった場合は、次回のAPI呼び出し時に再取得する。
取得済みの場合は、エンティティの生成・検索や文字列の再探索を行わない。

ライブラリ独自の毎tick処理は行わない。
`slim_checker.is_slim` を直接参照する場合は、先に公開APIを呼び出して最新の判定へ更新する。
旧方式からの更新時には、オフライン分も含む判定キャッシュを一度だけ無効化する。

プレイヤー以外を実行者にした呼び出しは失敗する。

### 判定の制約

従来と同じく、プロフィールのBase64文字列の380～520文字目を調べる方式。
この範囲外にあるスリム情報や、テクスチャ情報が存在しない場合のUUIDに基づくデフォルトスキンは判定対象外。

### 検証

26.3の公式サーバーのコマンドパーサーとルートテーブルのシリアライズ処理で検証。
GameTest環境では、空・短い入力、3通りの検出パターン、検索範囲末尾などの12ケースを実行。
合成プロフィールを設定したテスト用プレイヤーでも、スリム／ワイド各3ケースについて公開API、初回取得、キャッシュ、退出時の統計加算による再取得、連続退出、一時エンティティ削除を確認（計18ケース）。
旧方式のオフラインキャッシュの無効化、移行後の再読み込み時のキャッシュ維持、プレイヤー以外からの呼び出しも確認。
実際のクライアントから接続してのスキン表示・再接続確認は未実施。
